MÉTODO 01 Disponible

Regla del Rectángulo

Utiliza rectángulos de altura constante, evaluados en el extremo izquierdo de cada subintervalo.

Integral aproximada —
I ≈ h · Σ f(xᵢ), i = 0, …, n − 1

Cada rectángulo conserva su altura.

MÉTODO 02 Disponible

Regla del Trapecio

Une puntos consecutivos de la función con segmentos rectos para formar trapecios.

Integral aproximada —
I ≈ h/2 [f₀ + 2Σfᵢ + fₙ]

La aproximación sigue segmentos lineales.

MÉTODO 03 Disponible

Simpson 1/3

Utiliza interpolaciones parabólicas sobre grupos de dos subintervalos.

Integral aproximada —
I ≈ h/3 [f₀ + 4Σf(impar) + 2Σf(par interior) + fₙ]

Requiere que n sea par.

MÉTODO 04 Disponible

Simpson 3/8

Utiliza interpolaciones cúbicas sobre grupos de tres subintervalos.

Integral aproximada —
I ≈ 3h/8 [f₀ + 3Σf(restantes) + 2Σf(múltiplos de 3 interiores) + fₙ]

Requiere que n sea múltiplo de tres.

07

Aprende integración numérica

Fundamentos y conceptos importantes.

∫

¿Qué es la integración numérica?

Es el conjunto de técnicas que permiten aproximar integrales definidas mediante operaciones aritméticas y valores de una función.

h

¿Qué representa h?

Es la anchura de cada subintervalo. Se calcula mediante h = (b − a) / n.

▥

¿Por qué cambian los resultados?

Los métodos emplean diferentes figuras: rectángulos, trapecios, parábolas o polinomios cúbicos.

≈

¿Qué método puede ser más preciso?

Para funciones suficientemente suaves, Simpson suele ofrecer mayor precisión. Sin embargo, depende de la función y del intervalo.

n

Restricciones de Simpson

Simpson 1/3 requiere n par. Simpson 3/8 necesita n múltiplo de tres. El programa no altera automáticamente n.

±

Área con signo

Las regiones sobre el eje x contribuyen positivamente; las inferiores contribuyen negativamente a la integral definida.
